# CloudflareSpeedTest 项目结构

## 项目概述

**CloudflareSpeedTest** 是一个用 Go 语言编写的 Cloudflare CDN 速度测试工具。它可以测试 Cloudflare CDN（或其他 CDN）的各个 IP 地址的延迟和下载速度，帮助用户找到最快的 IP。在原项目基础上，新增了结果上报、定时任务管理和 Docker 容器化支持。

- **项目语言**: Go 1.24+
- **主要功能**: TCP 延迟测速、HTTP 延迟测速、下载速度测试、结果上报、定时任务、Docker 容器化
- **输出格式**: CSV 文件
- **模块路径**: `github.com/XIU2/CloudflareSpeedTest`

## 核心文件详解

### main.go - 项目入口

- **功能**: 命令行参数解析、程序流程控制
- **职责**:
  - 解析用户输入的命令行参数（延迟测速线程数、次数、下载测速配置等）
  - 调用 task 模块进行测试
  - 输出测试结果到 CSV 文件
  - 调用 utils 模块中的 report 功能上报结果（可选）
  - 调用 utils 模块中的 scheduler 功能管理定时任务（可选）
- **核心函数**:

| 函数 | 说明 |
|------|------|
| `main()` | 主流程：测速 → 导出CSV → 打印结果 → 上报（可选） |
| `handleReport()` | 处理测速后上报逻辑 |
| `handleReportOnly()` | 仅上报模式，跳过测速直接上报已有结果 |
| `buildReportConfig()` | 构建上报配置对象 |
| `handleSchedulerList()` | 列出定时任务 |
| `handleSchedulerDelete()` | 删除定时任务 |
| `handleSchedulerCron()` | 通过 cron 表达式创建定时任务 |
| `handleSchedulerInteractive()` | 交互式定时任务管理 |
| `buildCurrentArgs()` | 构建当前命令行参数列表（用于定时任务） |
| `checkUpdate()` | 检查版本更新 |

- **支持的参数分组**:

| 分组 | 参数 | 说明 |
|------|------|------|
| 测速参数 | `-n`, `-t`, `-dn`, `-dt`, `-tp`, `-url` | 延迟/下载测速配置 |
| 过滤参数 | `-tl`, `-tll`, `-tlr`, `-sl` | 延迟/速度/丢包率过滤 |
| 输出参数 | `-p`, `-f`, `-ip`, `-o`, `-dd`, `-allip` | 结果输出和IP段配置 |
| 上报参数 | `-report`, `-report-only`, `-report-file`, `-report-port` 等 | 结果上报配置 |
| 定时参数 | `-scheduler`, `-scheduler-list`, `-scheduler-delete`, `-scheduler-cron` 等 | 定时任务管理 |
| 其他参数 | `-v`, `-h`, `-debug` | 版本、帮助、调试模式 |

### go.mod & go.sum - 依赖管理

- **功能**: Go 模块依赖声明和锁定
- **Go 版本**: 1.24
- **主要依赖**:

| 依赖 | 版本 | 用途 |
|------|------|------|
| `github.com/VividCortex/ewma` | v1.2.0 | 指数加权移动平均（用于带宽计算） |
| `github.com/cheggaaa/pb/v3` | v3.1.7 | 进度条库 |
| `github.com/fatih/color` | v1.18.0 | 彩色输出库 |
| `github.com/mattn/go-isatty` | v0.0.20 | 终端检测库 |

### ip.txt & ipv6.txt - 测试数据

- **功能**: 存储 Cloudflare 的 IP 地址段
- **格式**: 每行一个 IP 或 IP 段（CIDR 格式）
- **用途**: 程序从这些文件读取需要测试的 IP

### airport_codes.json - 机场代码映射

- **功能**: 存储 IATA 机场代码到地区名称的映射关系
- **用途**: 在 HTTPing 模式下识别 Cloudflare 地区代码对应的实际地区
- **结构**: JSON 格式，包含机场代码、中文名称、地区和国家信息

## task 模块 - 核心测速功能

### ip.go - IP 地址处理

- **功能**: IP 地址段解析和随机 IP 生成
- **主要接口**:

| 函数/变量 | 类型 | 说明 |
|-----------|------|------|
| `InitRandSeed()` | 函数 | 初始化随机数种子 |
| `IPFile` | 变量 (string) | IP 段数据文件路径，默认 `ip.txt` |
| `IPText` | 变量 (string) | 直接指定的 IP 段数据 |
| `TestAll` | 变量 (bool) | 是否测速全部 IP，默认 false |
| `Routines` | 变量 (int) | 并发测速线程数，默认 200 |
| `PingTimes` | 变量 (int) | 单个 IP 测速次数，默认 4 |
| `TCPPort` | 变量 (int) | 测速端口，默认 443 |
| `URL` | 变量 (string) | 测速地址，默认 `https://cf.xiu2.xyz/url` |
| `Timeout` | 变量 (time.Duration) | 下载测速超时时间 |

### tcping.go - TCP 延迟测速

- **功能**: 通过 TCP 连接测试延迟
- **机制**:
  - 创建与目标 IP 指定端口的 TCP 连接
  - 测量连接建立时间（RTT）
  - 多次测试求平均延迟
- **核心接口**:

| 函数/类型 | 说明 |
|-----------|------|
| `Ping` | 延迟测速结构体 |
| `NewPing()` | 创建 Ping 实例 |
| `(*Ping).Run()` | 执行延迟测速 |
| `(*Ping).FilterDelay()` | 按延迟上限/下限过滤 |
| `(*Ping).FilterLossRate()` | 按丢包率过滤 |

### httping.go - HTTP 延迟测速

- **功能**: 通过 HTTP 请求测试延迟
- **机制**:
  - 发送 HTTP HEAD/GET 请求到指定 URL
  - 测量 HTTP 响应时间
  - 支持指定有效的 HTTP 状态码
- **核心变量**:

| 变量 | 类型 | 说明 |
|------|------|------|
| `Httping` | bool | 是否启用 HTTPing 模式 |
| `HttpingStatusCode` | int | 有效 HTTP 状态码 |
| `HttpingCFColo` | string | Cloudflare 地区码过滤 |
| `HttpingCFColomap` | map | 地区码映射表 |
| `MapColoMap()` | 函数 | 加载机场代码映射 |

### download.go - 下载速度测试

- **功能**: 测试从指定 IP 的实际下载速度
- **核心接口**:

| 函数/变量 | 说明 |
|-----------|------|
| `TestDownloadSpeed(data)` | 对延迟测速结果进行下载测速 |
| `MinSpeed` | 下载速度下限（MB/s） |
| `TestCount` | 下载测速 IP 数量 |
| `Disable` | 是否禁用下载测速 |

### color.go - 彩色输出

- **功能**: 提供控制台彩色输出
- **导出变量**: `Red`, `Green`, `Yellow`, `Cyan` 等彩色输出实例
- **基于**: fatih/color 库

### progress.go - 进度条

- **功能**: 显示测试进度
- **基于**: cheggaaa/pb 库

### airport_codes.json - 机场代码数据

- **功能**: 提供机场代码到地区名称的映射
- **加载函数**: `LoadAirportCodes()` 在 main.go 中调用
- **用途**: 增强 HTTPing 模式下的地区识别功能

### report.go - 结果上报功能

- **功能**: 将测速结果上报到 Cloudflare Workers API 或 GitHub
- **核心数据结构**:

| 类型 | 说明 |
|------|------|
| `Config` | 上报配置（Workers 域名、UUID、GitHub Token 等） |
| `PreferredIP` | 优选 IP 数据（IP、端口、名称） |
| `CloudflareIPResult` | CSV 解析后的测速结果 |
| `GitHubContentResponse` | GitHub API 响应（文件 SHA） |

- **核心接口**:

| 函数 | 说明 |
|------|------|
| `ReportResults(resultFile, cfg, target, port)` | 上报入口函数，根据 target 分发到不同上报方式 |
| `UploadToCloudflareAPI(cfg, results, port)` | 上传到 Cloudflare Workers API |
| `UploadToGitHub(cfg, results, port)` | 上传到 GitHub 仓库 |
| `ReadResultCSV(filePath)` | 读取并解析 CSV 结果文件 |
| `FormatPreferredIPs(results, port)` | 格式化为 Workers API 数据格式 |
| `FormatGitHubContent(results, port)` | 格式化为 GitHub 文件内容格式 |
| `LoadConfig(path)` | 加载上报配置文件 |
| `SaveConfig(path, cfg)` | 保存上报配置文件 |

- **上报流程**:

```
读取 result.csv → 解析 CSV 数据 → 根据 reportTarget 选择上报方式
  ├─ cloudflare → 检查配置 → GET 检查现有IP → DELETE 清除旧数据 → POST 上传新数据
  └─ github → 检查配置 → GET 检查文件是否存在 → PUT 创建/更新文件
```

- **重试机制**:
  - 最大重试次数：3 次
  - 重试间隔：2 秒
  - 仅对服务端错误（HTTP 5xx）和网络错误进行重试
  - 客户端错误（HTTP 4xx）直接返回

- **配置持久化**: 配置文件默认路径 `.cloudflare_speedtest_config.json`，优先级为命令行参数 > 配置文件

### scheduler.go - 定时任务功能

- **功能**: 跨平台定时任务管理
- **核心数据结构**:

| 类型 | 说明 |
|------|------|
| `TaskType` | 任务类型枚举（Cron/Daily/Hourly/Weekly） |
| `Task` | 任务实体（名称、类型、调度、命令、启用状态） |
| `TaskManager` | 任务管理器 |

- **核心接口**:

| 函数 | 说明 |
|------|------|
| `NewTaskManager()` | 创建任务管理器实例 |
| `(tm).CreateTask(name, taskType, schedule, command)` | 创建定时任务 |
| `(tm).DeleteTask(name)` | 删除定时任务 |
| `(tm).ListTasks()` | 列出所有定时任务 |
| `(tm).EnableTask(name)` | 启用定时任务（仅 Windows） |
| `(tm).DisableTask(name)` | 禁用定时任务（仅 Windows） |
| `(tm).GetTaskStatus(name)` | 获取任务状态 |
| `GenerateCommand()` | 生成可执行文件路径 |
| `PrintTaskList(tasks)` | 打印任务列表 |

- **跨平台实现**:

| 操作 | Linux/macOS | Windows |
|------|-------------|---------|
| 创建任务 | `crontab` | `schtasks /create` |
| 删除任务 | `crontab` | `schtasks /delete` |
| 列出任务 | `crontab -l` | `schtasks /query` |
| 启用/禁用 | 手动编辑 crontab | `schtasks /change` |

- **Cron 表达式验证**: 验证 5 字段格式（分 时 日 月 周）

## 工作流程

### 完整测速流程

```
1. 读取 ip.txt 和 ipv6.txt
   ↓
2. 解析 IP 地址段，生成测试 IP 列表
   ↓
3. TCP/HTTP 延迟测速（可并发，默认 200 线程）
   ↓
4. 根据延迟结果排序，选取最优 IP
   ↓
5. 对最优 IP 进行下载速度测试
   ↓
6. 结果汇总、过滤
   ↓
7. 导出 CSV 结果文件
   ↓
8. （可选）上报结果到 Cloudflare Workers API 或 GitHub
   ↓
9. （可选）运行 script/ 中的脚本自动应用优选 IP
```

### 仅上报流程

```
1. 读取已有的 result.csv 文件
   ↓
2. 解析 CSV 数据
   ↓
3. 根据 -report 参数选择上报方式
   ↓
4. 上报到 Cloudflare Workers API 或 GitHub
```

### 定时任务流程

```
1. 用户通过 -scheduler 参数交互式创建任务
   ↓
2. 根据操作系统选择任务创建方式
   ↓
3. Linux/macOS: 写入 crontab
   ↓
4. Windows: 创建 schtasks 计划任务
   ↓
5. 任务按计划自动执行测速
```

## 项目特点

- **高效并发**: 支持最多 1000 个并发线程测速
- **多种测速模式**: TCP 和 HTTP 两种延迟测速方式
- **灵活过滤**: 支持按延迟、丢包率等条件过滤结果
- **结果上报**: 支持 Cloudflare Workers API 和 GitHub 两种上报方式
- **仅上报模式**: 无需重新测速即可直接上报已有结果
- **定时任务**: 跨平台定时任务管理（crontab/schtasks）
- **Docker 支持**: 完整的容器化部署方案，支持多架构
- **自动化支持**: 提供脚本快速应用优选 IP 到系统
- **跨平台**: 支持 Windows、Linux、macOS
- **轻量级**: 单一二进制文件，无其他依赖
- **机场代码映射**: 内置机场代码数据库，增强地区识别

## 基本使用

```bash
# 编译项目
go build

# 基本测速（默认配置）
./cfst

# 自定义配置
./cfst -n 200 -t 4 -dn 10 -dt 10 -tp 443

# 使用 HTTP 模式
./cfst -httping -url "https://cf.xiu2.xyz/url"

# 指定 Cloudflare 地区
./cfst -cfcolo HKG,SGP,NRT

# 测速并上报到 Cloudflare Workers API
./cfst -report cloudflare -report-worker-domain example.com -report-uuid your-uuid

# 测速并上报到 GitHub
./cfst -report github -report-github-token ghp_xxxx -report-github-owner username -report-github-repo repo

# 仅上报已有结果（无需重新测速）
./cfst -report-only -report cloudflare -report-file result.csv -report-worker-domain example.com -report-uuid your-uuid

# 创建定时任务
./cfst -scheduler

# 列出定时任务
./cfst -scheduler-list

# 删除定时任务
./cfst -scheduler-delete task_name

# Docker 运行
docker compose up

# Docker 定时任务模式（通过环境变量）
docker run -e CFST_CRON="0 2 * * *" cfst:latest
```
